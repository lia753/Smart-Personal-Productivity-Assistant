# 🚀 Smart Personal Productivity Assistant

A modern desktop productivity application built using **Java Swing** that helps users manage daily tasks, track productivity, maintain notes, and interact with a rule-based AI assistant.

---

## ✨ Features

- 🤖 AI Rule-Based Chat Assistant
- ✅ Task Management (Add, Complete, Delete)
- 📝 Notes Manager
- 📊 Productivity Dashboard
- 📈 Weekly Analytics Chart
- 🔥 Daily Streak Tracking
- 🏆 Achievement Badges
- 🎯 Productivity Score
- 📄 Export Productivity Report
- 💾 Persistent Data Storage using Text Files

---

## 🛠️ Tech Stack

- Java
- Java Swing
- AWT
- Object-Oriented Programming (OOP)
- File Handling

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/lia753/Smart-Personal-Productivity-Assistant.git
```

2. Open the project in VS Code or IntelliJ IDEA.

3. Compile the project:

```bash
javac *.java
```

4. Run the application:

```bash
java ChatBot
```
